# Major versions are capped deliberately.
#
# These were unpinned, so a fresh CI runner resolved pandas 3.x while
# development ran on 2.3. `pd.to_numeric(errors="ignore")` was deprecated in
# pandas 2.2 and REMOVED in 3.0, so the dataset build passed locally and died in
# Actions. The pipeline runs unattended every Friday and fails closed, which
# means an upstream major release lands as a matchweek with zero bets placed and
# an alert issue nobody expected.
#
# Caps buy the right to upgrade on purpose, with the test suite as the gate,
# rather than on whatever PyPI resolved that morning.
